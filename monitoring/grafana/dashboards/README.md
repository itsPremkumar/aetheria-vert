# Aetheria Vertical AI Platform — Grafana Dashboard

This directory contains Grafana dashboards for monitoring the Aetheria platform.

## Dashboards

- `aetheria-fleet.json` — Overview of all vertical AI services
- `aetheus-perf.json` — Performance metrics (latency, throughput)
- `aetheria-health.json` — Health checks and alerts

## Usage

Dashboards are automatically loaded by Grafana via the provisioning configuration.
Place dashboard JSON files in this directory.
